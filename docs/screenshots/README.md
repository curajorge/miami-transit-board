# App screenshots

Captured from the running mobile web app at 390 × 1000 CSS pixels using an isolated browser. These are real UI captures using the public feeds available at capture time, including any explicitly labeled rough estimates. They are documentation images, not live arrival information or final Google Play listing assets.

- `ride-light.png`: journey board in light mode.
- `ride-dark.png`: journey board in dark mode.
- `settings.png`: appearance preferences in Settings.

No personal phone status bar, notifications, account details, or device identifiers are included. Map screenshots are omitted until map tiles can be reliably loaded in the capture environment.

To refresh: run `npm start`, use a clean browser at this viewport, wait for the feed refresh to settle, capture both themes and Settings, and inspect every image before committing. Never stage screenshots from a personal phone without checking for private information.
